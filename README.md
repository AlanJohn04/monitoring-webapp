# Dockerized Monitoring System

## Stack
- React frontend
- Flask backend
- Prometheus
- Grafana
- Node Exporter
- cAdvisor

## Run Locally

```bash
docker compose up --build
```

## Services

- Frontend: http://localhost:3000
- Backend: http://localhost:5000
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3001
